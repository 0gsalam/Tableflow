# Firebase Authentication

Този етап добавя основа за вход с Firebase Authentication.

## Включване във Firebase Console

1. Отворете Firebase проекта.
2. Влезте в Authentication.
3. Натиснете Get started.
4. В Sign-in method включете Email/Password.
5. Създайте първи потребител от Users.

## Конфигурация в приложението

Копирайте настройките от Firebase Console в:

```text
public/js/firebase-config.js
```

Докато стойностите започват с `ПОПЪЛНИ_`, приложението показва екран за настройка и не опитва връзка с Firebase.

## Какво е готово

- Екран Вход
- Вход с имейл и парола
- Запазване на сесията в браузъра
- Защитено Табло
- Изход
- Български съобщения за грешки
