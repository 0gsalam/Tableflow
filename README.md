# TableFlow

TableFlow е уеб приложение за управление на ресторантски маси, резервации и изчакващи клиенти.

Приложението е изцяло на български език и е оптимизирано основно за използване от телефон.

## Какво може

- Вход с имейл и парола
- Управление на маси
- Карта на ресторанта
- Преместване и редакция на маси
- Създаване на резервации
- Проверка кои маси са свободни за избран час
- Избор на една или няколко маси за резервация
- Списък с днешни резервации
- Изтриване на резервации с потвърждение
- Добавяне на изчакващи клиенти
- Изтриване на изчакващи клиенти
- Отделни данни за всеки потребител

## Технологии

- HTML
- CSS
- JavaScript
- Firebase Hosting
- Firebase Authentication
- Cloud Firestore
